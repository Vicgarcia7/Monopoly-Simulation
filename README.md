# Monopoly Simulation

A (mainly) python-based analysis on Monopoly and Monopoly-like board games.

## Project Overview

Every Monopoly game has some degree of variability, however, regardless of how vast and oftentimes random some players' strategies are, the following question will arises: is there a way to consistently *win* at the game through a repetition of patterns and choices even with random dice throws?

Of course, if replicable, consistent patterns are found within this analysis, an "optimal" way of playing or "higher-percentage decisions" may be deduced from these studies.

## Work in Progress

This is currently an on-going project where some other objectives, hypotheses and tools are yet to be applied/used.

## Tools

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib

## Project Goals

- Analyze the board's natural patterns
- Study how patterns affect the in-game core mechanics and decision-making
- Study how game dynamics scale with player count and whether distinct
  player-count ranges produce recurring strategic or behavioral patterns
- Study if a specific amount of players produce an outlying best performing strategy
- Understand if there is a rock-paper-scissor-like strategy meta-game
